# Movie Recommendation System

## Project Overview

A content-based movie recommendation system built using Python, NLP, and Scikit-Learn.

## Features

- Content-based filtering
- NLP text processing
- Cosine similarity recommendations
- TMDB movie poster integration

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- NLTK
- Streamlit
